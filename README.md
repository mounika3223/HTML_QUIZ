# HTML Quiz Website

An interactive HTML Quiz Website built using **HTML, CSS, and JavaScript**. The project allows users to answer multiple-choice HTML questions, track their score, skip questions, and view their final percentage and pass/fail result.

## Features

- Multiple-choice HTML questions
- Interactive quiz interface
- Score tracking
- Negative marking for incorrect answers
- Skip question functionality
- Automatic question navigation
- Percentage calculation
- Pass/Fail result
- Responsive design
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Quiz Scoring

- Correct answer: **+1 mark**
- Wrong answer: **-0.25 mark**
- Skipped question: **0 mark**
- Passing percentage: **50%**

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/mounika3223/HTML_QUIZ.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start the quiz and answer the questions.
